Sourced from this repository (main.py, app/api/router.py, microservices, algorithms, and integrations). ZenK Impact connects sponsor circles, schools, students, vendors, mentors, parents, and corporates — with Kia AI, ZenQ/ZQA scoring, KYC, and closed-loop marketplace spending.

Architecture Principles (as implemented)

Presentation: Persona dashboards on Vercel
API Security: JWT cookies, rate limits, headers
Intelligence: Kia + ZenQ/ZQA algorithms
Business: Persona microservices in one API
Memory: Neon Postgres + Cloudinary
Integration: ICICI, SMTP, LLM providers

Key Platform Capabilities

  • Multi-persona onboarding: Sponsor, member, student, school, vendor, mentor, corporate, parent — with KYC and DPDPA-aligned consent
  • Sponsor circles: Budget, members, enrollments, chat, impact pulse, vendor cart spending
  • School ↔ circle enrollment: Student linking, ZQA reports, CSV/PDF imports
  • Closed-loop marketplace: Vendor catalog, promotions, checkout against circle funds
  • Disbursements: Circle payees + ICICI corporate gateway flow
  • Kia AI: Operating intelligence across dashboards and circle chat with safety rules
  • Impact scoring: ZenQ (engagement) and ZQA (academic / Bloom’s / SEL composite)
  • Privacy: Student pseudonyms, group-level data sharing rules, Shield content moderation
  • Deploy shape: Railway-oriented API + Vercel frontends
