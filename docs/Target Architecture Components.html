Communication Pattern

All modules are mounted on a single FastAPI api_router (app/api/router.py). Callers authenticate via JWT bearer or HttpOnly cookies. Background work is handled with asyncio / request-scoped service calls (no Celery/Redis queue in this repo).

  • Synchronous REST: Dashboards, KYC, marketplace, admin ops
  • Async I/O: SQLAlchemy async sessions, httpx to LLM providers
  • Event briefings: Kia messages written into school panels / chat on domain events
  • External handoffs: ICICI disbursement redirects, SMTP send, Cloudinary uploads
