Flow Characteristics

  • Request/response REST: Primary interaction model across all persona dashboards
  • Async I/O: Database and LLM calls use asyncio; no Celery worker fleet in-repo
  • Event briefings: Kia writes contextual messages on enrollments, budgets, reports, marketplace events
  • External handoffs: Cloudinary uploads, SMTP email, ICICI disbursement gateway
  • Deterministic scoring: ZenQ/ZQA computed in-process from stored metrics
