Key Technology Decisions (repo reality)

  • Modular FastAPI monolith: Persona routers as microservices folders, one deployable API
  • Neon + async SQLAlchemy: Serverless Postgres with asyncpg pooling
  • LLM-first intelligence: Gemini/Groq for Kia; deterministic ZenQ/ZQA for scoring fairness
  • ICICI for disbursements: Corporate gateway — not Razorpay in this codebase
  • SMTP for email: Optional, feature-flagged — not SendGrid/Twilio
  • Cloudinary for media: KYC and marketplace assets without self-hosted object storage
  • Railway + Vercel: API and UI split with cookie/CORS bridging for production
